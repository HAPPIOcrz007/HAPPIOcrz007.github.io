Welcome! This first post doubles as a **cheat sheet** for what a blog post can contain.

## Text styling

You can write **bold**, *italic*, ~~strikethrough~~ and `inline code`. Colored text uses the same
syntax as the rest of the site: =(#e8510f)this is orange=, =(#2da44e)this is green= and you can
mix it with **=(#1890ff)bold blue=**.

Links work too — [my GitHub](https://github.com/HAPPIOcrz007) opens in a new tab. To link to
another post on this site, use `[text](#post-2)`.

## Images

Put images next to the post as `1_1.png`, `1_2.png`, … and reference them by number:

## Quotes, code and tables

> Simplicity is prerequisite for reliability.

Fenced code blocks get a language label, syntax highlighting and a **Copy** button. Put the
language after the opening fence (`cpp`, `python`, `bash`, `js`, `ts`, `json`, `html`, `css`,
`sql`, `java`, `rust`, `go`):

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // fast IO
    ios::sync_with_stdio(false);
    vector<int> v = {3, 1, 2};
    sort(v.begin(), v.end());
    cout << "Hello, blog! " << v[0] << "\n";
}
```

```python
def fib(n: int) -> int:
    """Return the n-th Fibonacci number."""
    return n if n < 2 else fib(n - 1) + fib(n - 2)

print(fib(10))  # 55
```

```bash
g++ -O2 -std=c++17 main.cpp -o main && ./main < input.txt
```


## Embeds

Embed any web page with `{embed=true}` on its own image-style line — it renders as an iframe:

![Anthropic](https://www.anthropic.com){embed=true}

Give it a fixed size instead of the default 16:9 box with `{embed=true, width=600, height=300}`.

## Sizing images

Add `{width=..}` and/or `{height=..}` after an image to cap its size — handy for icons or wide
banners. Give one and the other defaults to auto so the image keeps its aspect ratio:

![A small icon](img:1){width=64}

## PDFs

PDFs are attached exactly like images: `<blog>_<n>.pdf`. The post shows the first page; clicking
it opens the whole PDF in the browser's PDF viewer in a new tab.

![Attached PDF — click to open the full document](pdf:2){page=1}

Jump straight to a specific page with `{page=N}` — the preview shows that page, and clicking opens the PDF at that page:

![Second page of the same PDF](pdf:2){page=2}
