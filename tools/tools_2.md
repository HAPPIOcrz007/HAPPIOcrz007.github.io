A static, single-page logger for daily competitive programming practice. Paste a problem link or type a name, start the timer, and stop it when you finish (no pausing). Then add a completion screenshot, a difficulty tag (easy, medium or hard) and topic tags. Notes support markdown, pasted images, and code blocks for C++, Python, JavaScript, Java and Rust. Each entry locks into a callout, and the top of the page shows total time, day span, problems per hour with a difficulty line, and rank-coloured Codeforces and LeetCode cards. One click prints a report with your name and profile links, in whichever theme you've picked. Everything is saved in the browser.
